# ВСМ — сценарный тренажёр для проводников

> Интерактивное обучающее приложение для подготовки проводников высокоскоростной магистрали к сложным рабочим ситуациям.

Проект разрабатывается в рамках кейса **«Геймификация для ВСМ»** Хакатона Московского транспорта.

## О проекте

Тренажёр создаёт безопасную виртуальную среду, в которой проводник может пройти рабочие сценарии, принять решения в условиях ограниченного времени и увидеть последствия своих действий.

Сценарии посвящены реальным ситуациям, возникающим во время поездки: конфликтам между пассажирами, медицинским инцидентам и вопросам обслуживания.

## Планируемые возможности

- нелинейные сценарии с несколькими вариантами развития событий;
- таймер на принятие критических решений;
- шкалы лояльности пассажира и безопасности;
- подробный разбор действий после завершения сценария;
- профиль проводника и прогресс по компетенциям;
- достижения, уровни и таблица лидеров;
- аналитика сильных сторон и областей для развития.

## Цель проекта

Помочь проводникам развивать навыки принятия решений, общения с пассажирами и работы в нештатных ситуациях без риска для реальных людей.
